## Designbeslutninger
- **Entitet (H2):** valgte «varemerke som name + legalName + parentOrganization» (mest komplett), ikke minimal variant. Holdt synlig tekst (titler/nav/footer-merkenavn «Trygt Overvann AS») urørt — kun strukturerte data endret.
- **sameAs (M2):** personlig LinkedIn forkastet pga Bengts COWI-ansettelse (se memory `linkedin-cowi-constraint`). Brukte nøytrale entitet-lenker i stedet.
- **Plassering (M4):** valgte å fjerne presis plassering (ikke oppgi gateadresse), beholde «Bergen» som område — passer serviceområde-virksomhet, eksponerer ikke hjemmeadresse.
- De tre K1-bildene ble IKKE auto-erstattet med liknende eksisterende filer (ingen åpenbar match) — markert med TODO til brukeren skaffet ekte filer.
